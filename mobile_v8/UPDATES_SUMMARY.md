# 📋 Итоговые обновления Mobile v8

## ✨ Последние добавления

### 1. 💾 Сохранение чата

**Функция:** Автоматическое сохранение истории чата + экспорт

**Как работает:**
- Каждое сообщение автоматически сохраняется в LocalStorage
- Кнопка 💾 в заголовке чата для экспорта
- Три формата: TXT, JSON, CSV

**Когда использовать:**
- Сохранить важный чат после звонка
- Отправить коллеге (TXT)
- Загрузить в Google Sheets (CSV)
- Архивировать (JSON)

**Файл:** [CHAT_HISTORY.md](CHAT_HISTORY.md)

---

### 2. 📁 Передача файлов

**Функция:** Отправка файлов до 100 MB через P2P

**Как работает:**
1. Установи видеозвонок
2. Кнопка 📎 станет синей
3. Нажми и выбери файл
4. Собеседник получит с кнопкой Download

**Почему кнопка 📎 серая?**
- Потому что нет соединения!
- Сначала установи звонок → тогда кнопка включится

**Файл:** [FILE_TRANSFER.md](FILE_TRANSFER.md)

---

### 3. 📺 Адаптивная трансляция экрана

**Функция:** Автоматическая подстройка качества при слабом интернете

**Как работает:**
- Селектор качества: Ultra/High/Medium/Low/Auto
- Auto режим снижает качество при RTT > 80ms
- Индикатор соединения: 🟢/🟡/🔴
- Кнопка Sync (↻) для форсированного обновления

**Когда использовать:**
- Auto режим — автоматическое управление
- Low режим — на слабом интернете
- ↻ Sync — если экран зависнул

**Файл:** [SCREEN_QUALITY.md](SCREEN_QUALITY.md)
