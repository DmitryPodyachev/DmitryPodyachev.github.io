# Mobile v8 — WebRTC Video Call & Screen Share

## Новое в v8 🎉

### Адаптивная трансляция экрана при слабом интернете

**Проблема:** При плохом соединении экран "зависает" и не показывает изменения.

**Решение:**

1. **Автоматическая подстройка качества**
   - Система мониторит RTT (задержку) и потерю пакетов
   - При высокой задержке автоматически снижает разрешение и FPS
   - Меньше данных = быстрее передача = меньше зависаний

2. **Селектор качества**
   - Ultra (1920×1080, 30fps, 5Mbps)
   - High (1280×720, 30fps, 2.5Mbps)
   - Medium (960×540, 24fps, 1.5Mbps)
   - Low (640×360, 15fps, 0.8Mbps)
   - Auto (автоматический)

3. **Индикатор соединения**
   - 🟢 Зелёный = хорошее (RTT < 80ms)
   - 🟡 Жёлтый = среднее (RTT 80-150ms)
   - 🔴 Красный = слабое (RTT > 150ms)

4. **Кнопка Sync (↻)**
   - Принудительно передаёт текущий кадр
   - Если экран "зависнул" — нажми Sync

## Быстрый старт

1. Открой `index.html` в браузере
2. Скопируй свой ID или ссылку
3. Отправь собеседнику
4. Жди входящего вызова или нажми "Call" + введи его ID
5. Для экрана: нажми "Screen" → выбери качество → "↻ Sync" если нужно

## Технологии

- **WebRTC** — P2P видео/аудио
- **PeerJS** — упрощение WebRTC API
- **Canvas Blur** — размытие фона через canvas
- **Service Worker** — автономная работа
- **LocalStorage** — сохранение настроек
