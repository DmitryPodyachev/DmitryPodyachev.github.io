# 💾 Сохранение чата

## Что это?

Все сообщения чата автоматически сохраняются в **LocalStorage** браузера и могут быть экспортированы в файл.

## Как это работает?

### 1️⃣ Автосохранение

- Каждое сообщение (отправленное или полученное) автоматически сохраняется
- Сохраняется в `localStorage` под ключом `vc_chat_history`
- История остаётся даже после закрытия браузера

### 2️⃣ Экспорт чата

**Кнопка 💾** в заголовке чата позволяет скачать чат:

```
┌──────────────────────────────┐
│ Chat             [💾]        │ ← нажми сюда
├──────────────────────────────┤
│ [История сообщений]          │
└──────────────────────────────┘
```

**При нажатии на 💾:**
- Появится диалог
- **OK** — экспортировать как JSON
- **Cancel** — экспортировать как TXT

## Форматы экспорта

### 📝 TXT (простой текст)

```
[12:34] Вы: Привет!
[12:35] Собеседник: Привет! Как дела?
[12:36] Вы: Отлично! А ты?
```

**Когда использовать:**
- Быстрое просмотрение в любом редакторе
- Email пересылка
- Максимальная совместимость

### 📊 JSON (структурированные данные)

```json
[
  {
    "from": "me",
    "text": "Привет!",
    "time": "12:34"
  },
  {
    "from": "peer",
    "text": "Привет! Как дела?",
    "time": "12:35"
  }
]
```

**Когда использовать:**
- Импорт в базы данных
- Обработка скриптами
- Архивирование

### 📈 CSV (Excel/Sheets)

```csv
Time,From,Message
"12:34","Вы","Привет!"
"12:35","Собеседник","Привет! Как дела?"
"12:36","Вы","Отлично! А ты?"
```

**Когда использовать:**
- Импорт в Excel, Google Sheets
- Анализ данных
- Группировка по времени

## Где находится файл?

Файл сохраняется в папку **Downloads** (загрузки):

```
~/Downloads/chat_2024-10-09T18-30-45.txt
~/Downloads/chat_2024-10-09T18-30-45.json
```

**Имя файла** включает дату и время экспорта.

## Когда экспортировать?

### ✅ Можно экспортировать:
- **Во время звонка** — экспортировать текущую историю
- **После звонка** — вся история сохранена в LocalStorage
- **Через несколько дней** — даже если закрыть и снова открыть приложение

### ❌ Когда экспорт недоступен:
- Кнопка 💾 **серая** = соединение не установлено
- Нет сообщений в чате

## Пример использования

### Сценарий 1: Сохранить важный чат

1. Во время звонка нажимаешь 💾
2. Выбираешь **JSON** (если нужны структурированные данные)
3. Файл `chat_2024-10-09T18-30-45.json` скачивается
4. Можно загрузить в базу или Google Sheets

### Сценарий 2: Отправить чат коллеге

1. Нажимаешь 💾
2. Выбираешь **TXT** (красиво читается)
3. Прикрепляешь файл к email
4. Коллега видит весь чат

### Сценарий 3: Резервная копия

1. Каждый день нажимаешь 💾 в формате JSON
2. Загружаешь на Google Drive
3. История не теряется

## Технические детали

### Где хранится история?

```javascript
localStorage["vc_chat_history"] = JSON.stringify([
  { from: "me", text: "...", time: "..." },
  { from: "peer", text: "...", time: "..." }
])
```

**Размер:** ~1 KB на 100 сообщений

**Ограничение:** 5-10 MB в LocalStorage (для браузера)

### Автосохранение

- **Когда:** После каждого нового сообщения
- **Что:** Только открытые в текущий момент сообщения
- **Куда:** В LocalStorage браузера

### Экспорт

```javascript
exportChatAsFile("txt")   // сохранить как TXT
exportChatAsFile("json")  // сохранить как JSON
exportChatAsFile("csv")   // сохранить как CSV
```

## Безопасность

✅ **Приватно:**
- История хранится только на твоём компьютере
- Не передаётся на сервер
- Не видна другому пользователю

❌ **Ограничения:**
- Если очистить Cache → история удалится
- Разные браузеры → разные истории
- Разные профили → разные истории

## Часто задаваемые вопросы

**Q: История сохраняется автоматически?**
A: Да! Каждое сообщение автоматически сохраняется в LocalStorage.

**Q: Где найти скачанный файл?**
A: В папке Downloads браузера (обычно: ~/Downloads/ или Загрузки)

**Q: Можно ли восстановить удалённую историю?**
A: Нет, если очистить Cache браузера — история удалится безвозвратно.

**Q: Какой формат выбрать?**
A: 
- **TXT** — чтобы просмотреть
- **JSON** — для обработки/базы
- **CSV** — для Excel/Sheets

**Q: История видна другому человеку?**
A: Нет! История хранится только на твоём компьютере.

**Q: Сколько сообщений можно сохранить?**
A: Примерно 5,000-10,000 сообщений (зависит от браузера).

**Q: Если я переустановлю браузер?**
A: История удалится. Используй экспорт для резервной копии.

**Q: Работает на мобильных?**
A: Да! iOS Safari, Android Chrome — всё работает.
