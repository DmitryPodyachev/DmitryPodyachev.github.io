# 📞 WebRTC Video Call & Screen Share — Mobile v8

**Free peer-to-peer video calls, screen sharing, and file transfer — no server needed!**

## 🎯 Что это?

Полнофункциональное веб-приложение для видеозвонков с:
- ✅ Видео/аудио P2P соединения (WebRTC)
- ✅ Трансляция экрана с адаптацией к интернету
- ✅ Текстовый чат в реальном времени
- ✅ Передача файлов до 100 MB
- ✅ Контакты (сохраняются локально)
- ✅ Мобильная оптимизация
- ✅ PWA (работает офлайн)

## 🚀 Быстрый старт

### Для использования:
1. Откройте `index.html` в браузере
2. Скопируйте свой ID или ссылку
3. Отправьте собеседнику
4. Жди вызова или нажми "Call" + введи его ID

### Для разработки:
```bash
cd mobile_v8
python -m http.server 8000
# Открой http://localhost:8000 (или https для getDisplayMedia)
```

## 📊 Новое в v8

### 🆕 Адаптивная трансляция экрана при слабом интернете

**Проблема:** Экран зависает на медленном интернете.

**Решение:**
1. **Селектор качества** — выбери Ultra/High/Medium/Low/Auto
2. **Автоматическая адаптация** — система сама снижает качество при RTT > 80ms
3. **Индикатор соединения** — 🟢/🟡/🔴 показывает качество сети
4. **Кнопка Sync** — принудительно передать кадр

Подробно: [SCREEN_QUALITY.md](SCREEN_QUALITY.md)

## 📁 Передача файлов

**Как отправить файл:**

1. Установи видеозвонок (кнопка "Call" + контакт)
2. Дождись "Connected" ✅
3. Нажми кнопку 📎 (Attach File)
4. Выбери файл (до 100 MB)
5. Собеседник получит файл с кнопкой Download

**Важно:** Кнопка 📎 активируется только **после установки соединения**!

Подробно: [FILE_TRANSFER.md](FILE_TRANSFER.md)

## 🐛 Известные проблемы

### v8 vs v7

| Проблема | v7 | v8 |
|----------|----|----|
| Экран зависает на слабом интернете | ❌ | ✅ |
| Нет входящего видео на iPhone | ❌* | ✅ |
| Адаптивное качество экрана | ❌ | ✅ |
| Индикатор соединения | ❌ | ✅ |

*v7 исправляет проблему с входящим видео из v6

### Ограничения

- Не работает за WebRTC-несовместимыми прокси
- Требует HTTPS для некоторых функций
- getDisplayMedia недоступна на мобильных ОС
- Максимум 100 MB на файл

## 🚀 Развертывание

### Локально
```bash
# Python 3
python -m http.server 8000

# Node.js
npx http-server
```

### На сервер
1. Скопируй содержимое `mobile_v8/` на сервер
2. Обеспечь **HTTPS**
3. Оптимально: используй CDN для иконок

### PWA установка
- На мобильном нажми "Install" или "Добавить на экран"
- Появится иконка
- Работает офлайн (базовые функции)

## 💡 Советы

### Для быстрой трансляции экрана
1. Используй режим "Low" на слабом интернете
2. Нажми "↻ Sync" если экран "зависнул"
3. Проверь индикатор соединения (🔴 = плохо)

### Для быстрой передачи файлов
1. Сожми файлы архивом (ZIP, RAR)
2. Передавай последовательно (не одновременно)
3. На хорошем интернете — до 5 Mbps
