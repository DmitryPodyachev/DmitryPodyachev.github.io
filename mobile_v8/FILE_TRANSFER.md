# Передача файлов (File Transfer)

## Как передать файл?

### Пошагово:

1. **Установи соединение** 
   - Нажми "Call" и выбери контакт, или
   - Жди входящего вызова и нажми "Accept"
   - Дождись статуса "Connected" ✅

2. **Откроется кнопка 📎 (Attach File)**
   - Если видишь серую кнопку 📎 — соединение ещё не установлено
   - Кнопка активируется после подтверждения видеозвонка

3. **Нажми кнопку 📎**
   - Откроется выбор файла на компьютере

4. **Выбери файл**
   - Максимум 100 MB
   - Любой тип файла (jpg, pdf, zip, doc и т.д.)

5. **Подтверди передачу**
   - Появится прогресс-бар с процентом
   - Время зависит от размера файла и скорости интернета

6. **Собеседник получит файл**
   - Файл появится в чате с иконкой типа (🖼️ для фото, 📄 для PDF и т.д.)
   - Кнопка "Download" для скачивания файла

## Ограничения

### Размер файла
- ✅ до 100 MB
- ❌ больше 100 MB → ошибка "File too large"

### Скорость передачи
- Зависит от интернета и качества видеозвонка
- На хорошем соединении (RTT < 80ms): ~1-5 Mbps
- На слабом соединении (RTT > 150ms): ~0.5-1 Mbps

### Одновременные передачи
- ⚠️ На раз может передаваться только 1 файл
- После завершения → можно отправить следующий

## Проблемы и решения

### Проблема: Кнопка 📎 серая (disabled)
**Решение:** Сначала установи видеозвонок
1. Нажми "Call" + выбери контакт
2. Дождись "Connected" ✅
3. Кнопка 📎 станет синей

### Проблема: "Chat need call" (ошибка)
**Решение:** Соединение прервалось
1. Повтори звонок
2. Проверь интернет
3. Попробуй снова

### Проблема: File too large
**Решение:** Файл больше 100 MB
1. Сожми архивом (7zip, WinRAR)
2. Разбей на части
3. Отправь несколько файлов

### Проблема: Передача медленная/зависает
**Решение:** Слабое соединение
1. Проверь интернет (v8: смотри индикатор 🟢/🟡/🔴)
2. Уменьши качество видео
3. Закрой другие приложения
4. Используй проводное соединение

### Проблема: Файл не скачивается
**Решение:**
1. Проверь папку загрузок (Downloads)
2. Разреши всплывающие окна в браузере
3. Проверь дисковое пространство

## Технические детали

### Как работает передача?

1. **Инициация**
   - Отправляется метаинформация: имя, размер, тип, ID

2. **Передача чанками**
   - Файл разбивается на куски по 16 KB
   - Каждый кусок отправляется отдельно
   - Задержка 10 мс между кусками (не перегружать сеть)

3. **Приём**
   - Получатель собирает куски в буфер
   - После всех кусков → создаёт Blob

4. **Завершение**
   - Файл появляется в чате с кнопкой Download
   - Нажатие → скачивание на компьютер

### Буфер размер
- Всего: 100 MB максимум
- Один кусок: 16 KB
- Кусков: до 6,250 штук

### WebRTC Data Channel
- Надёжная передача (без потерь)
- Шифрование по умолчанию
- P2P (данные не идут на сервер)


## Совет для быстрой передачи

1. **Используй архивы**
   - ZIP/RAR меньше сжимают, быстрее
   - 7Z хорошо сжимает, медленнее распаковывается

2. **Передавай последовательно**
   - Дождись 100% одного файла перед следующим
   - Не отправляй много файлов одновременно

3. **Проверь интернет**
   - На v8 смотри индикатор качества соединения
   - 🟢 зелёный = хорошо, можно большие файлы
   - 🔴 красный = плохо, лучше сжми или раздели

4. **При зависании**
   - Прерви звонок (Hang up)
   - Повтори звонок
   - Отправь файл заново

## FAQ

**Q: Где хранятся загруженные файлы?**
A: В папке Downloads браузера (как обычно)

**Q: Можно ли передать папку?**
A: Нет, только отдельные файлы. Архивируй папку в zip перед отправкой.

**Q: Файл передался, но не скачивается?**
A: Проверь права на диск, дисковое пространство, разреши загрузки в браузере.

**Q: Как быстро передаётся файл?**
A: 1-5 Mbps на хорошем интернете, 0.5-1 Mbps на слабом.

**Q: Безопасна ли передача файлов?**
A: Да! WebRTC Data Channel зашифрован, данные не идут на сервер.
