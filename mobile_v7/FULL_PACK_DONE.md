## 🔊 Детали реализации:

### **Звук (Web Audio API):**
```javascript
function playRingtone() {
  const audioContext = new AudioContext();
  
  // Первый тон (800Hz, 400ms)
  oscillator1.frequency.value = 800;
  oscillator1.start();
  
  // Второй тон (600Hz, 400ms) через 500ms
  setTimeout(() => {
    oscillator2.frequency.value = 600;
    oscillator2.start();
  }, 500);
  
  // Повтор через 2 секунды
  setTimeout(beep, 2000);
}
```

**Преимущества:**
- ✅ Не нужны audio файлы
- ✅ Маленький размер кода
- ✅ Работает везде (Web Audio API поддерживается)
- ✅ Легко остановить

### **Вибрация:**
```javascript
navigator.vibrate([200, 100, 200, 100, 200]);
// █══█══█
```

### **Уведомления:**
```javascript
if (Notification.permission === "granted") {
  new Notification("Incoming call", {
    body: peerId,
    icon: "icon-128.png",
    tag: "videocall" // Заменяет старые
  });
}
```

### **Отмена файла:**
```javascript
// Отправитель
function cancelFileTransfer() {
  if (currentUpload && dataConn.open) {
    dataConn.send({ 
      type: "file-cancel", 
      fileId: currentUpload.fileId 
    });
  }
  currentUpload = null;
  hideFileProgress();
}

// Получатель
if (msg.type === "file-cancel") {
  incomingFiles.delete(msg.fileId);
  hideFileProgress();
  setStatus("Cancelled by peer", "err");
}
```
