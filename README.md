# WebRTC
Free call and chat with screen sharing. https://ein.pp.ua/ and https://mossy-mirage-rgz6.here.now/

Just open index.html in the browser, grant permission for access to Mic and Camera.
Then share link or "Your ID" - other person can open link and video call with you.

Examples:
https://dmitrypodyachev.github.io/    - monolit html
https://dmitrypodyachev.github.io/v4/ - separated css and js
